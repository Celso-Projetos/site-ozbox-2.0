# Site Ozbox 2.0

Site do Centro de Treinamento OzzyBox em Pouso Alegre, MG. A página apresenta o treino híbrido, encaminha o agendamento à Tecnofit e abre consultas de planos pelo WhatsApp.

[Site publicado](https://celso-projetos.github.io/site-ozbox-2.0/)

## Desenvolvimento

```sh
npm ci
npm run dev
npm run typecheck
npm run build
npm run preview
```

A prévia do build abre em `/site-ozbox-2.0/`. O GitHub Actions publica a pasta `dist` no GitHub Pages a cada alteração em `main`. A URL do GitHub Pages é usada nos metadados e no sitemap. O arquivo `_headers` foi fornecido com o projeto e só se aplica a hospedagens que dão suporte a esse formato.

## Conteúdo público

Preços, horários, frequências e condições são consultados nos canais do box. As fotografias de treino são ilustrativas. A seção de avaliações leva ao perfil no Google.
